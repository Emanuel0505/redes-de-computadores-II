Quero aprender, de forma prática e didática, como funciona e como configurar um ambiente de DNS + Reverse Proxy + servidores web usando Docker Compose.

Estou estudando redes e reverse proxy. Já fiz um laboratório usando Docker Compose com:

1 container funcionando como reverse proxy

2 containers funcionando como servidores web

Agora quero aprender a configurar um servidor DNS usando CoreDNS em outro container.

Meu objetivo é entender como construir uma arquitetura semelhante a:

                    Internet
                       │
                       ▼
                 ┌──────────────┐
                 │ Reverse Proxy│
                 │    :80/:443  │
                 └──────┬───────┘
                        │
               ┌────────┴────────┐
               ▼                 ▼
          ┌──────────┐      ┌──────────┐
          │   Web 1  │      │   Web 2  │
          │   :80    │      │   :80    │
          └──────────┘      └──────────┘

                    DNS
                     ▲
                     │
                ┌────┴─────┐
                │ CoreDNS  │
                │   :53    │
                └──────────┘


Quero especificamente aprender a fazer o CoreDNS ser responsável pela resolução DNS, em vez de depender da resolução de nomes fornecida pelo Docker.

Como instalar e configurar o CoreDNS dentro de um container.

Como configurar uma rede Docker com IPs estáticos.

Como fazer os outros containers utilizarem o CoreDNS como servidor DNS.
